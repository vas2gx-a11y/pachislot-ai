# アナスロ データ取り込みツール

アナスロ(ana-slo.com)の日別ホールデータを取得してCSV化し、機種別・台番別・曜日別などに集計する。

日別ページ(例 `https://ana-slo.com/2026-08-22-楽園大宮店-data/`)のHTMLには
`<table id="all_data_table">` という全台データの表がそのまま入っている。

| 機種名 | 台番号 | G数 | 差枚 | BB | RB | ART | 合成確率 | BB確率 | RB確率 | ART確率 |
|---|---|---|---|---|---|---|---|---|---|---|
| ネオアイムジャグラーEX | 2084 | 7,482 | -1,571 | 20 | 29 | 0 | 1/152.7 | 1/374.1 | 1/258.0 | 1/0.0 |

画面上はボタンを押すまで隠れているが、HTMLには最初から書き出されているので、
画像解析ではなくHTMLから直接読める。楽園大宮店の場合、1日あたり約1,100台分。

---

## 一番早い使い方: `anaslo_import.sh`

保存したページを1コマンドで変換したいだけなら、Claudeに頼まずこのスクリプトを直接叩くのが一番速い。
Chromeで保存したフォルダのパスを渡すだけで、日別ページ・一覧ページのどちらでも
中身を見て自動判定し、CSV・台別データ・日別データを作って `data/` に置く。

```bash
tools/anaslo_import.sh ~/Downloads/ana-slo.com-2026-08-22-.../
```

```
対象ページ: 2026/08/22 楽園大宮店 データまとめ - アナスロ
→ 日別ページとして処理します(店舗: 楽園大宮店)
...
できたファイル:
  台別データ取り込み用: data/units_楽園大宮店_2026-08-22.txt
  日別データ取り込み用: data/paste_楽園大宮店.txt
  分析用CSV(蓄積分):   data/anaslo_楽園大宮店.csv
```

日別ページを取り込むたびにCSVへ追記され(重複日は上書き)、店舗トップの「データ一覧」ページを
一度取り込んでおくと(`data/list_<店名>.html` に控えられる)、以降の日別ページ取り込みで
一覧側の値とも自動で合成される。店名が自動判定できない場合は第2引数で指定する。

```bash
tools/anaslo_import.sh ~/Downloads/ana-slo.com-.../ 楽園大宮店
```

以降の「手順1〜3」は、このスクリプトの中身(何が起きているか)の説明でもあるので、
個別に集計したい・仕組みを知りたいときに読む。

---

## 前提: Pythonから直接は取得できない

ana-slo.com はCloudflareのbot対策が有効で、`requests` や `curl` からのアクセスは
**403 (Just a moment...)** で弾かれる。そのため取得はブラウザ側で行い、解析・集計をPython側で行う。

```
Chromeで開いているページ          →  anaslo_fetch.js  →  CSV
                                                          ↓
                                                      anaslo.py agg  →  機種別/台番別/曜日別の集計
```

---

## 手順1: ブラウザでCSVを作る

1. Chromeで https://ana-slo.com/ の任意のページを開く
2. `F12` → **Console** タブ
3. [`anaslo_fetch.js`](anaslo_fetch.js) の中身を全部コピーし、先頭の `CONFIG` を書き換えて貼り付け、Enter

```js
const CONFIG = {
  store: '楽園大宮店',   // 店舗名(アナスロのページ表記どおりに)
  days: 30,              // 何日分さかのぼるか
  endDate: '',           // 起点日 'YYYY-MM-DD'(空なら昨日から)
  delayMs: 3000,         // 1日分ごとの待ち時間(ミリ秒)
};
```

4. 進捗がコンソールに出て、終わるとCSVが自動でダウンロードされる

```
[1/30] 2026-07-24: 1104台 / 総差枚 -35,721
[2/30] 2026-07-25: 1102台 / 総差枚 +12,043
...
完了: 33,061行 / 30日分
```

休業日など存在しない日は自動でスキップされる。
1日分ずつ間隔を空けて順番に取得するので、30日分でおよそ2〜3分かかる。
`delayMs` は短くしすぎないこと(相手のサーバーに負荷をかけない)。

> 別のやり方として、日別ページをブラウザで「名前を付けて保存」してから
> `anaslo.py parse` にかけてもよい(下記)。

## 手順2: 集計する

ダウンロードしたCSVをそのまま渡す。

```bash
python3 tools/anaslo.py agg ~/Downloads/anaslo_楽園大宮店_2026-07-24_2026-08-22.csv --by machine
```

```
対象: 33061行 / 30日分(2026-07-24〜2026-08-22)

[機種別]  ※平均差枚の高い順
対象                          件数    総差枚       平均差枚   平均G数    勝率     最高       最低       合成
------------------------------------------------------------------------------------------------------------
マギアレコード 魔法少女まど…  840     +48,297      +1,725     8,161      50.0%    +9,524     -5,120     1/117.5
...
```

### 集計オプション

| オプション | 意味 |
|---|---|
| `--by machine` | 機種別(既定) |
| `--by number` | 台番別 |
| `--by machine-number` | 機種+台番別 |
| `--by date` | 日付別 |
| `--by weekday` | 曜日別 |
| `--by store` | 店舗全体 |
| `--days 30` | 直近30日に絞る |
| `--since 2026-07-01 --until 2026-07-31` | 期間指定 |
| `--machine ジャグラー` | 機種名の部分一致で絞る |
| `--number 2419` | 台番号で絞る |
| `--weekday 土` | 曜日で絞る |
| `--zorome` | ゾロ目日(11日・22日)と月日ゾロ目(8/8など)のみ |
| `--min-samples 5` | サンプル数が少ないグループを除外 |
| `--limit 50` | 表示件数 |
| `--out path.csv` | 集計結果もCSVに書き出す |

よく使う組み合わせ:

```bash
# 直近90日、ジャグラーのシマを台番別に(5日以上のデータがある台だけ)
python3 tools/anaslo.py agg data/anaslo.csv --by number --machine ジャグラー --days 90 --min-samples 5

# ゾロ目日に強い機種を探す
python3 tools/anaslo.py agg data/anaslo.csv --by machine --zorome --min-samples 10

# 曜日ごとの出方の差
python3 tools/anaslo.py agg data/anaslo.csv --by weekday --days 90
```

## 手順3(任意): 保存したHTMLから作る場合

ブラウザで日別ページを保存した場合は `parse` を使う。ファイル名か本文から日付・店舗名を判定する。

```bash
python3 tools/anaslo.py parse ~/Downloads/*.html --out data/anaslo_楽園大宮店.csv
python3 tools/anaslo.py parse ~/Downloads/2026-08-23*.html --out data/anaslo_楽園大宮店.csv --append
```

`--append` は既存CSVに追記する。同じ 日付×店舗×台番号 の行は新しい方で上書きされるので、
同じ日を2回取り込んでも重複しない。

## 「データ一覧」ページから日別データを登録する

店舗トップの**データ一覧**ページ(例: `楽園大宮店 データ一覧`)を丸ごと保存した `index.html` があれば、
アプリの店舗傾向ページにある**日別データの取り込み**欄に貼り付ける形へ変換できる。

```bash
python3 tools/anaslo.py daily --list ~/Downloads/ana-slo.com-.../index.html --out data/paste_楽園大宮店.txt
```

```
[一覧ページ] 楽園大宮店: 1763日分 (2021-09-11 〜 2026-08-22) / うち総差枚が入っているのは 6日
合計 1763日分 / 総差枚まで入っているのは 6日分
```

### 注意: 一覧ページには平均G数しか載っていない

アナスロの一覧ページは、**総差枚・平均差枚・勝率をほとんどの日で「–」と表示している**
(楽園大宮店の場合、1,763日のうち値が入っているのは6日だけ)。
保存に失敗したわけではなく、サイト側がそう出している。取れるのは日付と平均G数まで。

差枚まで埋めたい場合は、日別ページ由来のCSV(手順1・2で作るもの)を一緒に渡す。
日別ページの全台データから、店舗全体の 総差枚 / 平均差枚 / 平均G数 / 勝率 を計算して差し替える。

```bash
python3 tools/anaslo.py daily \
  --list ~/Downloads/ana-slo.com-.../index.html \
  --csv data/anaslo_楽園大宮店.csv \
  --out data/paste_楽園大宮店.txt
```

計算した平均G数がアナスロの一覧の表示と一致することは確認済み
(2026/08/22 楽園大宮店: 1,104台・平均G数 6,455 で一致。総差枚 -107,156 / 平均差枚 -97 / 勝率 42.1%)。

| オプション | 意味 |
|---|---|
| `--list path` | 保存した「データ一覧」ページの index.html |
| `--csv path` | parseで作った台別CSV(同じ日付があればこちらを優先) |
| `--days 90` | 新しい方からN日分だけ出す |
| `--out path` | 貼り付け用テキストの出力先(省略時は標準出力) |

出力は `日付 総差枚 平均差枚 平均G数 勝率` のタブ区切りで、そのまま
`/store_trends` の日別データ取り込み欄に貼れる(値のない欄は `-` になる)。

## 日別ページから台別データを登録する

日別ページ(`2026-08-22-楽園大宮店-data`)を保存した `index.html`、または `parse` で作ったCSVから、
アプリの**台別データの取り込み**欄に入れる形へ変換できる。台別データは1日ぶんずつ登録する。

```bash
python3 tools/anaslo.py units --html ~/Downloads/ana-slo.com-2026-08-22-.../index.html --store 楽園大宮店 \
    --out data/units_楽園大宮店_2026-08-22.txt
```

```
2026-08-22: 1104台 / 114機種
```

出力は機種ごとにまとめた形になる(アプリ側は、数値でない短い行を機種名の見出しとして読む)。

```
台番号	G数	差枚	BB	RB
スマスロ サンダーV
2001	7,148	+143	23	21
2002	5,826	+2,143	26	13
```

| オプション | 意味 |
|---|---|
| `--html path` | 保存した日別ページのHTML |
| `--csv path` | parseで作った台別CSV |
| `--date 2026-08-22` | 対象日(省略時は一番新しい日) |
| `--store 名` | 店舗名を明示する |
| `--out path` | 出力先(省略時は標準出力) |

**ART回数は出力していない。** アプリの台別データ(`store_units`)にART列がないため、BB/RBのみ入る。
AT機はBBが0でRBだけが入るので、AT機の初当りを見るときは `agg` 側のCSV(`art` 列がある)を使う。

## CSVの形式

`anaslo_fetch.js` と `anaslo.py parse` は同じ列を出す。

| 列 | 内容 |
|---|---|
| `date` | 対象日 `YYYY-MM-DD` |
| `store_name` | 店舗名 |
| `machine_number` | 台番号 |
| `machine_name` | 機種名 |
| `games` | G数 |
| `diff` | 差枚 |
| `bb` / `rb` / `art` | BB・RB・ART回数 |
| `total_rate` | 合成確率の分母(`1/152.7` → `152.7`) |
| `bb_rate` / `rb_rate` / `art_rate` | 各確率の分母 |
| `graph_max` / `graph_min` | 出玉グラフ上の最高差枚・最低差枚 |
| `graph_drawdown` | 最大下落幅(高値から一番大きく飲まれた枚数) |
| `graph_points` | グラフのサンプル点数 |

### 出玉グラフについて

日別ページには全台分のスランプグラフがChart.js用の配列として埋め込まれており、
`<canvas id="台番号">` の直後の `y_value`(その時点の差枚)から形を数値化している。
`x_value` は営業時間の経過を表す全台共通の目盛り(0〜243)で**ゲーム数ではない**ため、
同じ目盛りでも台によって回転数が違う。よってx軸は使わず、差枚の推移だけを見ている。

グラフはサンプリングされた点の集まりなので、最終点は表の`差枚`と数十枚ずれることがある。

確率の分母は、当たり0回で `1/0.0` と表示される欄を**空**にしている。
これは「確率0」ではなく算出不能な値で、そのまま0として扱うと平均が壊れるため。

集計時の合成確率は「平均の平均」ではなく **総G数 ÷ 総当たり回数**で出している。

## 設定予測アプリとの連携

`parse` で作ったCSVは、店舗傾向ページ(`/store_trends`)の
**「CSVから一括取り込み（台別＋日別）」**でそのまま登録できる。
1行が「1日×1台」なので、このファイル1つから台別データと日別データの両方が作られる
(日別の総差枚・平均差枚・平均G数・勝率は台別データから計算される)。
複数日がまとまっていても1回で取り込める。

取り込みファイルの上限は4MBで、1日あたり約110KB(1,100台)なので、目安として35日分ほど。
それを超える場合は期間を分けて取り込む。

日別だけ・台別だけを登録したい場合は `daily` / `units` で貼り付け用テキストを作る。


`--by store` の出力は、アプリの店舗傾向ページ(`/store_trends`)にある
**総差枚・平均差枚・平均G数・勝率**の入力欄にそのまま入る。
これまで画像から読み取っていた値を、実データから直接出せる。

```bash
python3 tools/anaslo.py agg data/anaslo_楽園大宮店.csv --by store --days 90
```

Pythonから使う場合は関数を直接呼べる(標準ライブラリのみで動作、追加依存なし)。

```python
import sys
sys.path.append("tools")
import anaslo

rows = anaslo.load_csv("data/anaslo_楽園大宮店.csv")
recent = anaslo.filter_rows(rows, days=30, machine="ジャグラー")
label, results = anaslo.aggregate(recent, by="number")
```

## 注意

- 取得したデータは個人の分析用に使うこと。再配布や転載は避ける。
- 取得間隔(`delayMs`)を詰めない。まとめて取るのは最初の1回だけにして、
  以降は前日分を1日ずつ足していくのが相手にも自分にも楽。
- ページの構造が変わると解析に失敗する。その場合は日別ページのHTMLで
  `all_data_table` を検索して、表の列構成を確認する。
